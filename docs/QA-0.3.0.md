## Reviewed fixes

The review found central failures in active payload transmission, captured POST replay, project import, tool route resolution, interception state synchronization, response/body preservation, request destinations, Unicode/MD5/JWT behavior, local API exposure and growing UI histories. Regression coverage now checks the affected semantics and complete browser workflows.

The narrow layout no longer scales the document with CSS zoom. Repeater panes stack, navigation and result tables scroll, rule editors fit the panel, and configuration/dialog content remains reachable. Wide layouts keep independent panes and cards.

## Limits of validation

The suite uses deterministic safe transports and local HTTP/HTTPS/WebSocket fixtures, including a positive and negative SSTI case. DVWA, Juice Shop and WebGoat were not run for this release; no lab precision/recall score or Burp Suite detection parity is claimed. Live paid AI endpoints, every third-party OSINT destination and all external scanner binaries were not exercised. Linux distributions other than the tested environment/CI runner, ARM and non-Linux platforms are not certified.

[Usage limits](USAGE.md#limits) document preview/export budgets, static rendering, inspection-only WebSockets and parallel replay without last-byte synchronization. [Testing](TESTING.md) explains how to reproduce the checks, and [release procedure](RELEASE.md) requires CI success before publication.
